# video-dub-cli

Single command to dub any video.

## Quick Start

```bash
dub run /path/to/input/talk.mp4 --source-lang en --target-lang zh
dub resume --project-dir ~/.hermes/dub-talk/
dub status --project-dir ~/.hermes/dub-talk/
dub clean --project-dir ~/.hermes/dub-talk/
dub validate --project-dir ~/.hermes/dub-talk/
```
