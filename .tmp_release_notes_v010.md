## video-dub-cli v0.1.0

First public release of `video-dub-cli`.

### Included in this release
- Single-entry CLI with `dub run`, `resume`, `status`, `clean`, `validate`
- Persistent project-state model via `.dub/state.json`
- End-to-end staged workflow for stems, ASR, ref-audio, translation, TTS, and final assembly
- Example configs for English→Chinese and Japanese→Chinese flows
- Operator docs, QA matrix, runbook, and handoff checklist
- Public-facing README and quickstart documentation

### Release positioning
This is an **operator-grade** release: suitable for real workflow usage, but not yet a universal zero-touch dubbing product for arbitrary video inputs.
